【安装包文件夹说明】（2026-10 更新 · 安装脚本 v2.0）

这一摞安装包是为了让你不碰 GitHub、不碰 claude.ai 也能把环境装齐。
（背景：claude.ai 在国内网络会被拦，提示 "region unavailable"；
 GitHub 直连又慢。所以能离线的都给你离线了。）

────────────────────────────────
先说重点：新版脚本会自己做「前置体检」，缺什么替你装什么

Claude Code 不是双击一下就完事的东西，它脚下踩着几样地基：
Node.js（要有，而且版本必须 22 以上）、npm、PATH 环境变量、磁盘空间、能连上的下载源。
以前少哪一样都得你自己去查；现在脚本会先逐项检查一遍：缺什么先提醒你，
然后（你按回车确认，或 15 秒自动继续）自动替你装好，再装 Claude Code，最后验证一遍。

  安装ClaudeCode-一键联网安装.bat   ← 推荐：联网安装（国内镜像，不需要魔法上网）
  安装ClaudeCode-离线安装.bat       ← 没网时用：从礼包里的离线包复制，全程不联网
  安装ClaudeCode-只检测环境.bat     ← 只体检、不装任何东西：想先看看缺什么就双击它

每次运行都会在「安装包」文件夹里留一份《安装日志-年月日-时间.log》，
出问题把它发给帮你的人，比截图有用得多。

────────────────────────────────
它到底检查了什么（本次新增的核心功能）

① Node.js 有没有装、版本够不够 —— Claude Code 官方要求 >= 22（老教程里写的 18 早就过期了）
② npm 能不能用、npm 的全局目录有没有在 PATH 里 —— 「装好了却敲不出 claude」九成卡在这里
③ 磁盘剩余空间 —— 低于 2GB 会提醒（装到一半失败多半是这个）
④ 网络与下载源 —— npmmirror 通不通；不通自动换官方源再试；两个都不通就劝你改用离线安装
⑤ 离线包完不完整（联网安装不看这项）
⑥ 是不是已经装过 Claude Code、有没有 claude 正在运行（离线覆盖前必须先关掉）
⑦ 管理员权限 —— 需要时装 Node 会自动申请提权，会弹一次 UAC，点「是」就行
⑧ 装完再验一遍 claude --version，确认命令真的能跑；跑不动会告诉你下一步该敲什么

缺 Node.js 时的自动安装顺序：
礼包自带的 node-v22.23.3-x64.msi（装之前校验数字签名，签名人 OpenJS Foundation，官方）
→ 从华为云镜像下载（约 30MB，同一版本）
→ 再用系统自带的 winget 兜底。

────────────────────────────────
按这个顺序装（顺序有讲究：先把"换发动机"的 CC Switch 备好、配好密钥，
最后装 Claude Code——它第一次打开就能直接用，不会卡登录）：

① （可选，推荐）node-v22.23.3-x64.msi
   Claude Code 的地基（Node.js 运行环境，来自华为云官方镜像）。
   双击 → 一路"下一步"装完。不用管它是什么，装完基本不会再想起它。
   也可以跳过这步：直接跑 ③，脚本发现没有 Node 会自己帮你装。

② CC-Switch-v4.0.4-Windows.msi
   给 Claude Code "换发动机"的图形工具（切到 DeepSeek）。
   双击安装。装完先放着，等 ③ 装完回来配置。

③ 安装ClaudeCode-一键联网安装.bat
   双击运行：先体检 → 缺的自动补齐 → 把 npm 切到国内镜像（npmmirror）→
   联网安装 Claude Code（实测无代理直连 18 秒装完，不需要魔法上网；
   万一被校园网拦截，脚本会自己换官方源再试一次，还不行就临时开代理重跑一次）。
   装出来的是"黑色终端窗口"——正常！但先别打开它，先做 ④。

④ 打开 CC Switch：右上角「+」→ 预设选 DeepSeek →
   粘贴你的 sk- 密钥 → 保存并切换。完成。

⑤ 现在打开 Claude Code 验收：终端输入 claude 回车，
   直接发"你好"能收到回复就成功了（不该出现登录页）。
   最后跑 配套文件\AI装机体检助手，全绿 ✔ 毕业。

装到一半断了/报错了怎么办？
→ 先看脚本留下的日志：安装包\安装日志-*.log（脚本最后一行也会打印路径）
→ 打开「启动我-AI开箱教室.html」→ 急救站，90% 的问题有自救办法。
→ 或者跑 配套文件\AI装机体检助手，它会告诉你缺什么、下一步干什么。

────────────────────────────────
Plan C：所有 .bat 都被拦截/跑不动时的最后手段（纯手动，一定可行）
1. 装 Node：双击 node-v22.23.3-x64.msi（MSI 安装器总是能装的）
   （礼包里没有这个文件的话，去 mirrors.huaweicloud.com/nodejs/v22.23.3/ 下载同名的那个）
2. 开命令行：按 Win 键 → 输入 cmd → 回车（打开黑色窗口）
3. 复制下面这一行，在黑色窗口里点鼠标右键（=粘贴），回车：

   npm config set registry https://registry.npmmirror.com && npm install -g @anthropic-ai/claude-code

4. 等它跑完（1~3 分钟），再双击装 CC-Switch-v4.0.4-Windows.msi，完事。
   （这行命令只用到 npm 和 Node，它们随第 1 步的安装包一起装上，
    不依赖你电脑上预装的任何工具；镜像走国内 CDN，不需要魔法上网。）
