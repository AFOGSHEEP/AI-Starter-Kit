# 30 分钟认识 AI 核心概念

> 目标：读完这一篇，你再看到"Agent""API""Token"这些词，不再头晕。
> 每个概念只讲三件事：**一句话定义 → 医学场景类比 → 对你的实际影响**。

---

## 开场：聊天机器人 vs Agent，差在哪？

- **普通聊天**（网页版 DeepSeek、ChatGPT）：像**电话咨询**。你问一句它答一句，它看不到你的电脑、记不了笔记、查完资料也没法帮你整理成文件。
- **Agent**（智能体）：像**给你配了个随叫随到的科研助理**。你说"把我文件夹里这 3 篇 PDF 读完，做个对比表格"，它会自己拆步骤：打开文件 → 逐篇阅读 → 提取数据 → 生成表格 → 存到你电脑上。**中间过程不需要你动手。**

Agent 的本质 = 大模型 + 自主拆解任务 + 调用工具（读文件、上网、跑代码）+ 循环执行直到交付。
你装的两个软件（Claude Code、DSH）就是两种不同的"Agent 工作台"。

---

## 第一层：它到底是个什么东西

### 1. 大语言模型（LLM）
- **一句话**：读完了几乎整个互联网文本后，学会"接话"的超级大脑。
- **类比**：一位把图书馆背下来的实习生，知识渊博，但**不查资料时全凭记忆说话**（这是后面"幻觉"问题的根源）。
- **影响**：它擅长总结、改写、推理、写东西；不擅长精确记忆（比如 exact 的药物剂量、文献编号）。

### 2. API 与 API Key
- **一句话**：API 是程序调用大模型的"官方窗口"；API Key 是你的专属通行证（一串 `sk-` 开头的密码）。
- **类比**：API = 医院的挂号窗口；Key = 你的就诊卡。**卡号别借人，扣的是你卡里的钱。**
- **影响**：网页聊天是"免费大厅"；API 是"付费贵宾通道"，Claude Code 和 DSH 走的都是它。你的 Key 泄露 = 别人拿你的余额干活，所以**只在软件设置里填，不要发给任何人、不要截图发群里**。

### 3. Token（令牌）
- **一句话**：AI 计费和计量的最小单位，约等于半个到一个汉字、或四分之一个英文单词。
- **类比**：医院按"项目"收费，AI 按 token 收费。
- **体感换算**：一页 A4（约 800 字）≈ 1000 token；一篇英文文献 PDF ≈ 1~2 万 token；一本 30 万字的书 ≈ 50 万 token。DeepSeek 的计价单位是"每 100 万 token"，日常任务根本用不了那么多——**读一篇文献约几分钱**。

### 4. 上下文窗口（Context Window）
- **一句话**：模型一次能"记在脑子里"的最大文字量，新模型已达 100 万 token（约一整本书）。
- **类比**：诊室里实习生的工作记忆——超出门诊量的病人信息就"挤出脑外"了。
- **影响**：对话太长后它会忘掉开头，这不是坏了，是正常现象。解决办法：开新对话，或让它"把结论先写进笔记/文件"。另外，塞进上下文的内容都按输入 token 计费，所以"把整本书扔给它"之前看看费用说明。

## 第二层：怎么跟它说话最有效

### 5. 提示词（Prompt）
- **一句话**：你对 AI 说的那段话就是提示词，质量决定产出质量。
- **类比**：写病历主诉。**"我不舒服" vs "转移性右下腹痛 6 小时，伴发热"**，得到的回应天差地别。
- **万能模板**（场景卡里反复用到）：
  > 【你是谁】+【我要什么】+【材料在哪】+【输出成什么样】+【有什么禁忌】
  > 例："你是医学统计顾问（角色）。请分析我文件夹里的 data.csv（材料），做组间比较并说明为什么选这个检验方法（目标），结果整理成论文三线表（格式）。我零编程基础，你全部自己完成（约束）。"

### 6. 系统提示词 / CLAUDE.md（岗前培训）
- **一句话**：一段长期生效的"员工守则"，每次对话自动生效，不用重复交代。
- **类比**：新助理上岗前的科室培训——"我导师是谁、我们组规矩是什么"。
- **影响**：工具包里附了《我的AI人设-CLAUDE.md》模板，放到你的工作文件夹里，AI 就会一直记得"我是医学研究生、零编程、说话要通俗、引用要真实"。

## 第三层：Agent 的本事从哪来

### 7. Agent（智能体）——见开场白
核心特征是**自主循环**：理解目标 → 制定计划 → 调工具执行 → 检查结果 → 修正 → 交付。你会在场景 3 里亲眼看到它自己写代码、自己跑、自己改错——而你一行代码都不用会。

### 8. 工具调用（Tool Use / Function Calling）
- **一句话**：让模型能"伸手"操作外界：读文件、上网搜索、执行代码、画图。
- **类比**：实习生光背书不够，还得会用 HIS 系统、会开检验单。
- **影响**：这正是"许愿式功能"的来源——你说愿望，它用工具实现。你会在 Claude Code 界面看到它每次伸手前会请求许可，**看不懂的许可可以拒绝，问它"你想干嘛"**。

### 9. MCP（Model Context Protocol，模型上下文协议）
- **一句话**：给 AI 接工具的统一插口标准，类似"USB-C 接口"。
- **类比**：USB-C 之前每种设备一根线；MCP 之后，任何工具做成标准插件，任何 AI 都能插。
- **影响**：DSH 的口号就是"万物皆插件"——装个文献插件、表格插件，Agent 能力就扩展一块。现阶段你**知道这个词、能看懂插件介绍**就够了，不必急着折腾。

### 10. RAG（检索增强生成）
- **一句话**：先去外部资料里检索，再基于检索到的内容回答，"开卷考试"代替"闭卷背诵"。
- **类比**：与其赌实习生记忆，不如让他**当场翻指南原文**再回答你。
- **影响**：让 Agent 先"读你给的 PDF / 联网搜索"再回答，可信度大幅上升。重要问题养成习惯：**"请基于我提供的文献回答，不要凭记忆"**。

### 11. 快速模型 vs 重度推理模型（flash 与 pro）
- **一句话**：同一家有两种档位——`deepseek-flash` 秒回、便宜、够日常；`deepseek-v4-pro` 会"打草稿深思"、更贵更强，留给难题。
- **类比**：门诊常规处理 vs 疑难病例多学科讨论。
- **影响**：日常任务用 flash（读文献、总结、改写）；统计设计、复杂综述逻辑、机制推理才请 pro 出场。**注意：Claude Code 里手动切换到 opus 档会被映射成 v4-pro 计费（约贵 4.5 倍），默认档别乱切。**

## 第四层：钱、风险与底线

### 12. 幻觉（Hallucination）
- **一句话**：模型一本正经地编造不存在的东西——假文献、假数据、假指南推荐。
- **类比**：实习生不好意思说"不知道"，硬编了个看似合理的答案。
- **影响**：**医学场景这是头号风险**。AI 给的参考文献（作者/期刊/PMID）、药物剂量、指南年份，使用前必须核实（详见避坑卡）。好习惯：在指令里加一句"不确定就明说，禁止编造文献"。

### 13. 上下文缓存（Context Cache）
- **一句话**：对话中重复出现的内容，平台会缓存，第二次起按"缓存命中"极低价计费。
- **类比**：复诊时病历已建好档，不用再收一遍问诊费。
- **影响**：对同一篇文献连续追问 10 个问题，往往只有第一问按全价算，后面近乎打折白送。**追问很便宜，换新话题才花钱。**

### 14. 计费时段（峰谷定价）
- **一句话**：DeepSeek 按北京时间分时段计价——工作日白天（9–12 点、14–18 点）全价，**晚上、周末、法定节假日一律半价**。
- **影响**：夜猫子科研党天然省钱。大任务（整晚跑综述）尽量放 18 点后或周末。

### 15. 速率限制（Rate Limit）
- **一句话**：平台限制每分钟请求数/并发数，超了会收到 429 报错。
- **类比**：专家门诊限号。
- **影响**：正常使用根本碰不到（学生档并发上限很高）。偶尔遇到"429"，等一分钟再发即可。

### 16. 隐私与脱敏
- **一句话**：通过 API 发送的内容会离开你的电脑，**凡是能定位到患者的字段，先脱敏再上传**。
- **影响**：这是红线，详见《患者隐私红线》。一句话版：姓名→"患者A"，住院号/生日/具体日期→打码或删除，原始病历照片永不直传。
