一套「开箱即用」的入门包，专为**不用编程、只想让 AI 帮忙做科研和过日子**的医学研究生准备。里面包含：

1. **一本 30 分钟读完的概念手册**——把 Agent、API 这些词彻底讲明白
2. **四步装机指南**——办卡、装软件、填密钥、验收，全程复制粘贴
3. **一份费用说明**——每次任务花几分钱还是几块钱，先看再花，心里不慌
4. **八个实战场景卡**——文献速读、综述、数据分析、润色、复习、PPT、生活、VOCALOID 创作，直接抄作业
5. **三张避坑卡**——患者隐私、AI 幻觉、常见报错

## 你将用到的两个软件（都装在 Windows 电脑上）

| 软件 | 是什么 | 适合干什么 |
|---|---|---|
| **Claude Code 桌面版** | 一个能直接操作你电脑文件夹的 AI 工作台 | 干活：读文献、处理 Excel、写文档、做 PPT |
| **DSH 桌面版**（DeepSeek Harness） | DeepSeek 官方开源的 Agent 运行环境，插件化 | 探索：体验"万物皆插件"的 Agent 玩法 |

两个软件背后都由 **DeepSeek API** 驱动——这是国内可直接充值使用的正规渠道，价格对学生极其友好（晚间和周末半价，读一篇文献几分钱）。

## 三步上手（详情见 02-装机指南）

1. **办卡**：注册 DeepSeek 开放平台 → 实名 → 充 20 元 → 生成一把 API Key（一串密码）
2. **装机**：装 Claude Code 桌面版和 DSH 桌面版，各填一次 Key
3. **开练**：打开「场景 1 - 文献速读」，复制那句话粘贴进去，看 AI 自己干活
