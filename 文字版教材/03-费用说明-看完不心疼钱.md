> 先说结论：**娱乐闲聊请用 DeepSeek 官方 App / 网页版（免费）；API 只留给 Agent 干活。**
> 按量付费、先充后用、余额用完自动停服——**不存在"被盗刷欠费"的风险**。学生日常科研，一个月大概 10~30 元。

---

## 一、计费原理（30 秒版）

- 按 **token** 计费（一页 A4 ≈ 1000 token），不按次数、不按时间。
- **输入**（你发给它的：文件、对话历史）和**输出**（它写给你的）分别计价，输出更贵。
- **缓存命中**（对话里重复出现的内容）便宜到近乎忽略——追问很划算。
- 预付费制：先充值，余额归零服务自动停，想再用再充。

## 三、场景账单（按 flash 空闲档估算）

| 场景 | 大约 token 用量 | 大约花费 |

## 六、防失控五招

1. **预付费天然保险**：余额用完即停，不会产生欠费，也不会被乱扣。
2. **娱乐分流**：日常聊天用免费的官方 App（chat.deepseek.com），别拿 API 烧钱聊天。
3. **大任务放晚上/周末**：自动半价，而且不占你白天门诊/实验时间。
4. **别乱切 opus 档**：Claude Code 里切到 opus 会被映射为 v4-pro 计费（约贵 4.5 倍）。日常保持默认（sonnet 位 = flash）。
5. **每周瞄一眼用量页**：platform.deepseek.com → 用量，异常暴涨说明有任务在空转，及时关掉。

## 七、常见误会澄清

- ❌"按次收费？" → 不，按 token。
- ❌"联网搜索额外收费？" → 搜索本身免费，但 Agent 会多读几页内容，多花一点输入 token（几分钱级）。
- ❌"余额会不会一夜被偷跑光？" → 只要不泄露 Key，且你在场时及时按停失控任务，几乎不可能。Key 不外传 + 任务结束就关软件。
