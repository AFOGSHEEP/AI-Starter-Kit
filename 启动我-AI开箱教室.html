    🔌 API 实操：让三个工具吃上你的 Key

    这一页是"动手版"API 课（概念在第 2 课学过了）。你的三个 Agent 工具——Claude Code、CC Switch、DSH——用的都是同一把 DeepSeek API Key、同一个账户余额，只是"插座形状"不同。

    🗺 先看全景：一把钥匙开三把锁

    📌 格局图 DeepSeek 开放平台（你的账户和余额）
      └─ 🔑 API Key（sk- 开头，唯一"电源"）
         ├─ 🤖 Claude Code：读 C:\Users\你\.claude\settings.json（装机向导已自动写好）
         ├─ 🔀 CC Switch：图形化"换发动机"面板，改的其实是同一个 settings.json
         └─ 🧩 DSH：在自己的 Settings → Models 里单独填一次 Key

    下面逐个讲。已经跑过「①开箱向导」的同学，前两个工具其实已经配好了——这一页教你看懂它写了什么、坏了怎么修、想改怎么改。

    🤖 Claude Code：配置文件在哪、写了什么

    Claude Code 每次启动都会读这个文件：C:\Users\你的用户名\.claude\settings.json。装机向导第 4 步写入的内容长这样（对照看懂每一行）：

    {
  "env": {
    "ANTHROPIC_BASE_URL":     "https://api.deepseek.com/anthropic",
    "ANTHROPIC_AUTH_TOKEN":   "sk-这里是你自己的Key",
    "ANTHROPIC_MODEL":        "deepseek-flash[1m]",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "deepseek-flash[1m]",
    "ANTHROPIC_DEFAULT_OPUS_MODEL":   "deepseek-flash[1m]",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL":  "deepseek-flash"
  }
}
    逐行翻译 BASE_URL：告诉它"别去官方 api.anthropic.com（要登录/美元），去 DeepSeek 的兼容接口"
    AUTH_TOKEN：你的钥匙 sk-xxx
    MODEL 三兄弟：把界面里的"Sonnet/Opus/Haiku"档位全部映射到 deepseek-flash（[1m] = 100万 token 长上下文版）
    ⚠ 常见坑 ① 地址还指向 api.anthropic.com = 一开会就"要求登录"的根源；
    ② 改完文件要重开 Claude Code 才生效；
    ③ JSON 里多/少一个逗号会整个失效——改崩了就重跑装机向导第 4 步一键重写

    ✅ 手动配置三步（或验证向导写的对不对）

    ① 按 Win + R 输入 %USERPROFILE%\.claude 回车，记事本打开 settings.json；
    ② 对照上面的模板核对/粘贴（Key 换成你自己的）；
    ③ 保存后开一个新的命令行窗口，输入 claude 回车 → 发一句"你好"。有回复 = 通电成功。
    日常两个好习惯对话里输 /model 随时看当前用的是哪个模型；输 /cost 看本次会话花了多少钱。人设文件 CLAUDE.md 的教学在「装机向导」第 4 步。

    🔀 CC Switch：给 Claude Code 换发动机的图形面板

    CC Switch 是个图形小工具，作用一句话：帮你改写上面那个 settings.json——和手动改是同一件事的"可视化版"。适合以后你想同时保留多个供应商（比如官方渠道 + DeepSeek）一键切换的场景。

    ✅ 添加 DeepSeek 供应商（四步）

    ① 打开 CC Switch，进供应商管理 → 添加；
    ② 名称随便填（如 DeepSeek）；
    ③ 接口地址填 https://api.deepseek.com/anthropic，Key 粘贴你的 sk-，默认模型填 deepseek-flash[1m]；
    ④ 保存并"切换/应用"到该供应商 → 打开 Claude Code 发"你好"验证。
    ⚠ 切换的副作用切换 = 整个 settings.json 被换写成那个供应商的配置。切去别家玩完，记得切回 DeepSeek，不然下次打开 Claude Code 会用错渠道（报"要求登录"九成是这个原因——去急救站对号入座）。

    🧩 DSH：在自己的设置里填同一把 Key

    DSH（DeepSeek Harness）是 DeepSeek 官方开源的 Agent 运行环境，口号"万物皆插件"。它不读 Claude Code 的配置文件，要在自己的设置里单独填一次——但用的是同一把 Key、扣同一个余额。

    ✅ 配置两步 + 验证

    ① 打开 DSH → Settings → Models → 找到 DeepSeek → 粘贴你的 sk- Key → 保存；
    ② 随便发一句"你好"，有回复即成功。不出结果时依次查：Key 是否保存、余额是否充足、网络是否正常（急救站有条目）。
    🔌 插件玩法（它存在的意义）基础会话之外，DSH 靠插件长本事：文献插件、表格插件……在它的插件市场里按需安装，Agent 能力就扩展一块。新手阶段先跑通"你好"，插件以后慢慢玩。

    🧪 选修：亲手"裸调"一次 API（10 分钟看懂计费）

    不经过任何 Agent 工具，直接跟 DeepSeek 服务器说一次话——做过一遍，"API、token、按量计费"就再也不抽象了。把 sk-xxx 换成你的 Key，存成 test.ps1 右键"使用 PowerShell 运行"，或在 PowerShell 里整段粘贴：

    # PowerShell 版（Windows 自带，零安装）
$key = "sk-换成你的Key"
$r = Invoke-RestMethod -Uri "https://api.deepseek.com/chat/completions" `
  -Method Post -ContentType "application/json" `
  -Headers @{ Authorization = "Bearer $key" } `
  -Body (@{
      model    = "deepseek-flash"
      messages = @(@{ role = "user"; content = "用一句话介绍你自己" })
      max_tokens = 50
    } | ConvertTo-Json -Depth 5)
"回复：" + $r.choices[0].message.content
"用量：" + ($r.usage | ConvertTo-Json -Compress)   # 看看花了几个 token
    读懂返回choices 是回复内容；usage 里的 prompt_tokens（你的问题）/ completion_tokens（它的回答）就是计费依据——输入约 ¥1/百万、输出约 ¥4/百万，一次对话不到一分钱。和「费用计算器」页正好对上。
    🚫 报错三件客 401：Key 错了/被删了 → 平台重新复制；
    402：余额不足 → 充值；
    429：发太快被限速 → 等一分钟。详细的去「急救站」。

    会写代码的同学也可以用 Python：pip install openai 后把 base_url 指向 https://api.deepseek.com、api_key 填你的 Key、模型名 deepseek-flash，其余和 OpenAI 官方库写法完全一样（DeepSeek 做了兼容）。
