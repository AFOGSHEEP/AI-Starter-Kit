【AI 开箱工具包 · 使用说明】

你只需要做一件事：
>>> 双击「①先双击我-开箱向导.bat」<<<
它会自动检测缺什么、依次自动安装（Node.js → Claude Code → CC Switch）、
引导你贴一次 API 密钥、最后自动打开教学页面。全程只需按回车 + 点"下一步"。
装过的会自动跳过，出问题随时重跑一遍即可。

之后的学习和使用：
- 教学 + 实战：双击「启动我-AI开箱教室.html」（向导结束时也会自动打开）
- 日常体检：双击 配套文件\AI装机体检助手-双击我.bat
- 卡住了：教学页面里的「急救站」有 90% 问题的自救办法

文件夹里的其他东西（向导会自动用到，一般不用手动碰）：
- 安装包\                            → 已替你下好的离线安装包（Claude Code 不用碰 GitHub）：
      ① node-v22.23.3-x64.msi（双击装，Claude Code 的地基）
      ② 安装ClaudeCode-一键联网安装.bat（装完①后双击，国内镜像自动装 Claude Code）
      ③ CC-Switch-v4.0.4-Windows.msi（双击装，给 Claude Code 换发动机用）
      顺序和说明详见 安装包\安装说明.txt
- 配套文件\AI装机体检助手-双击我.bat   → 真正的体检程序：检查软件装没装、配置对不对、
                                        密钥有没有效（还能一键写入推荐配置、打开官方下载页）
- 配套文件\我的AI人设模板-CLAUDE.md   → 装机向导第4步会用到（小程序里有手把手教学）
- 配套文件\备用-命令行配置.bat        → 备用方案（优先用 CC Switch 和体检助手）
- 文字版教材\                        → 同样内容的文字备份，供喜欢阅读的人（可不看不看）
