# 🩺 AI 开箱教室（AI-Starter-Kit）

> 给零编程基础医学生做的「AI Agent 开箱工具包」：
> **解压 → 双击一个文件 → 60 分钟后，AI 助理正式上岗。**
> 不碰 GitHub、不碰 claude.ai、不碰命令行（除非你想）。

---

## 为什么做这个

身边太多研究生朋友听说了 Agent 的"许愿式功能"——丢一个文件夹进去，AI 自己读文献、跑统计、出表格——却永远卡在第一步：看不懂 API、装不上工具、被付费方式吓退、被国内网络劝退。

这个工具包把"从零到第一个 Agent"压缩成一条链路：

```
双击 ①开箱向导.bat
   ↓ 自动装好 Node.js + Claude Code + CC Switch（离线包内置）
   ↓ 网页实时显示进度，唯一需要你做的事：去 DeepSeek 领一张"就诊卡"（密钥）
   ↓ 粘贴密钥，自动验证 + 写入配置
   ↓ 教学页面自动打开：6 节课 → 8 个实战场景 → 开工
```

## ✨ 功能特性

- **开箱向导**（PowerShell，GUI 优先）：自动检测已装组件、依次静默/半自动安装、写入前自动备份旧配置、可重复运行=可修复
- **网页实况联动**：向导每步把状态写成 `wizard-status.js`，教学页面（file:// 协议）用 JSONP 方式轮询渲染进度条、四步状态卡和日志——本地网页跨域限制下的可行方案
- **交互教学**：6 节概念课（Agent/API/Token/上下文/提示词/幻觉与隐私），全部用医学类比讲解，课后小测全对才算完成，进度自动保存
- **机器验收**：密钥自检（格式→余额→点火测试）、CLAUDE.md 拖拽验收（文件名/编码/内容纠错）、装机体检助手真读 `settings.json`——验证通过自动打勾，"✔机器已验证"
- **费用计算器**：按使用强度估算月费（DeepSeek 官方峰谷定价），对比包月方案，支持直连查询实时余额
- **场景弹药库**：8 个为医学研究生写好的提示词（文献速读/多文献综述/Excel 全自动统计/SCI 润色/出题/PPT/生活/VOCALOID），一键复制即用
- **国内网络适配**：claude.ai 地区封锁（实测 403）→ 走离线包 + npmmirror 镜像；GitHub 直连慢 → CC Switch/Node 安装包已内置并做 sha256 校验

## 🚀 快速开始

1. 解压压缩包
2. 双击 **`①先双击我-开箱向导.bat`**（被杀软拦截就选"允许"）
3. 照着浏览器页面走：拿到 DeepSeek 密钥 → 回黑色窗口右键粘贴 → 完成
4. 上课，然后去「场景弹药库」抄第一个作业

前置条件：Windows 10/11 x64；首次充值 20 元（按量计费，学生日常约 10~30 元/月）。

## 🧠 教学设计原则

- **类比优先**：API Key = 就诊卡，Token = 计费单位（一页 A4≈1000），缓存命中 = 复诊免问诊费，峰谷定价 = 晚上周末半价
- **先看到再理解**：向导跑完立刻能发"你好"收到回复；点火测试顺手展示这条消息花了几分钱
- **红线前置**：患者隐私脱敏、AI 编造文献（幻觉）、"AI 生成内容需人工核实"写进第 6 课和 CLAUDE.md 人设模板
- **降级链完整**：CC Switch（标准路径）→ 体检助手一键写入 → Plan C 手动命令，任何一环挂了都有下一步

## 💰 费用观

## 🛠 技术备注

- 教学程序为单文件 HTML，离线可用，进度存 localStorage，不上传任何数据
- PowerShell 脚本兼容 Windows 内置的 5.1，全部带 UTF-8 BOM（中文不乱码）
- 密钥只在页面内存/脚本运行期使用，验证请求直连 DeepSeek 官方域名，不经第三方
- 供应商管理推荐 CC Switch（[farion1231/cc-switch](https://github.com/farion1231/cc-switch)），本包内置 v4.0.4
