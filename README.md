## 它解决什么问题

身边太多朋友听说了 Agent 的"许愿式功能"——丢一个文件夹进去，AI 自己读资料、处理数据、出表格——却永远卡在第一步：

| 卡点 | 本工具包的答案 |
|---|---|
| API 是什么？Key 去哪领？ | 教学程序第 2 课 + 密钥图文教学卡（注册→实名→充值→创建，每步写清） |
| claude.ai 打不开 / 403 | 全程不访问：安装包离线内置，npm 走国内镜像 |
| GitHub 下载慢/失败 | Node.js（华为云镜像）和 CC Switch（sha256 已验）直接打进压缩包 |
| 配置文件是什么？环境变量怎么设？ | CC Switch 图形化一键写入；向导/体检助手也能自动写（写入前自动备份） |
| Token 计费会不会烧钱 | 费用计算器按使用强度估算 + 直连官方查实时余额；预付费、余额尽即停 |

| 装到一半报错了怎么办 | 14 条急救站自查 + 体检程序真读你的系统状态 + Plan C 一行命令兜底 |

## 深入各模块

### 1. 开箱向导（wizard.ps1）

一次双击完成全部安装，四步顺序经过刻意设计：

1. **Node.js**（离线 MSI）：弹安装窗等待完成 → 自动刷新当前进程 PATH → 复查
2. **CC Switch**（离线 MSI）：先装好"换发动机"的图形工具
3. **DeepSeek 密钥**：网页同步弹出图文教学（密钥是什么/去哪拿/怎么贴），终端 `Read-Host` 收密钥 → 直连官方验证（401/余额为 0 各有专属提示）→ 备份旧配置 → 写入 `~/.claude/settings.json`
4. **Claude Code**（npm）：此时配置已就位，装完首次启动直接可用——**规避登录墙**是把它放最后的原因

每步的状态（pending/running/waiting/need_key/ok/error/skipped）实时写入 `wizard-status.js`；任何一步失败不阻塞后续步骤，收尾输出完成度 n/4 与修复指引。

### 2. 教学教室（单文件 HTML，约 75KB，离线可用）

- **6 节概念课**：聊天 vs Agent / API 与 Key / Token 与计费 / 上下文与记忆 / 提示词 / 幻觉与红线。示例版类比以就医流程作比（API Key = 就诊卡、缓存命中 = 复诊免问诊费、峰谷定价 = 夜门诊半价），每课 5 分钟 + 2~3 道选择题，全对才解锁完成
- **上下文感知侧栏**：常驻左侧，随当前页面切换内容——课程页显示六课进度（点击直达并展开）、装机页显示五步分组进度、费用页实时显示估算月费、场景页显示索引、急救页显示高频条目；外加全局"下一步该干嘛"卡
- **费用计算器**：三个滑块（每日文献量/每日任务量/每月大活次数）× 模型档位 × 峰谷时段，实时算月费并画对比条（vs 包月套餐），支持填 Key 直连官方查真实余额和"还能用几个月"
- **急救站**：14 条 `<details>` 手风琴，每条=症状+按方抓药，覆盖 401/402/429、模型列表空、配置不生效、登录墙、DSH 连不上、Key 泄露、`.md` 是什么、bat 被拦截、网络自检失败定性……

### 3. 机器验收（不靠自觉打勾）

- **密钥三级体检**：① 输入即校格式（`sk-` 前缀+长度，分别提示"复制了一半/贴成密码"）② 查余额（密钥有效自动勾选装机项并标验证；余额 0 提前预告 402）③ 点火测试（真发一条消息，展示回复+token 用量+折算费用——用户第一次直观看到计费）
- **CLAUDE.md 拖拽验收**：FileReader 读文件，抓三个新手经典翻车点——文件名存成 `CLAUDE.md.txt`、编码存成 ANSI（检测 U+FFFD 替换符）、内容只贴一半；每个错误给具体修法；另有一键下载（Blob 直出）从根上杜绝
- **体检助手（check-ai.ps1）**：探测 Node/claude 命令、Claude 桌面版与 CC Switch（目录+注册表双探测）、DSH 主目录；解析 `settings.json` 报告 Base URL 指向（还指着 api.anthropic.com 会点破"这就是登录墙根源"）、密钥掩码与格式；菜单支持一键写入推荐配置（时间戳备份）、联网体检、打开官方下载页

### 4. 场景弹药库（可复制的提示词模板）

每个场景 = 目标说明 + 软件建议（Claude Code/皆可/免费 App）+ 一键复制提示词 + 注意事项。示例版 8 个：★文献速读、多文献综述、Excel 全自动统计（"代码你自己写自己跑，报错自己修"）、写作润色与审稿回复、出题复习、机制图与 PPT、生活省钱分工、VOCALOID 创作。模板结构统一：**角色+目标+材料+输出格式+约束**——学的是方法，不止是抄。

## 工作原理：向导与网页怎么联动

本地网页以 `file://` 打开时受跨域限制，`fetch()` 读不了本地文件。本项目的方案是 JSONP 风格的状态桥：

```text
wizard.ps1 ──每步写入──▶ wizard-status.js   （内容：window.WIZARD_STATUS = {...};）
教学网页   ──每 1.2s──▶ 动态 <script src="wizard-status.js?t=时间戳">
                          ↳ onload 读取 window.WIZARD_STATUS → 渲染进度/状态卡/日志
```

网页首次加载会探测状态文件是否存在（重试 3 次，容忍向导启动延迟）；向导结束后用户点"开始学习"写入 localStorage 标记，之后打开不再进入开箱页。密钥全程只在页面内存与脚本运行期存在，不落 localStorage、不进任何第三方请求。

## 网络策略与三级降级方案

**设计前提：目标用户网络无法稳定访问 GitHub 与 claude.ai。**

| 依赖 | 来源 | 实测 |
|---|---|---|
| Node.js | 华为云镜像 | 国内直连 |
| CC Switch | 已打进压缩包（sha256 比对官方 Release） | 无需网络 |
| Claude Code | npmmirror（registry + 平台二进制子包全量同步） | **无代理直连 18 秒装完，含 245MB win32 二进制** |
| DeepSeek API | api.deepseek.com | 国内直连 |

| 级别 | 方案 | 触发条件 |
|---|---|---|
| Plan A | 双击开箱向导，全自动 | 正常情况 |
| Plan B | 按 安装包/安装说明.txt 手动双击 ①→⑤ | bat 被杀软拦截/向导异常 |
| Plan C | 装 Node 后，cmd 里右键粘贴一行 `npm config set registry https://registry.npmmirror.com && npm install -g @anthropic-ai/claude-code` | 一切脚本都跑不动时（该命令只依赖第 1 步装好的 npm） |

npm 需不需要代理？——**不需要**（上表实测数据）；若被校园网/公司网拦截，临时开代理重跑即可。

## 可定制指南

教学程序是单个 HTML，所有课程文案、类比、场景提示词都是纯文本，直接搜索修改即可：

- **换类比体系**：搜索"就诊卡/复诊/门诊"替换为你受众熟悉的场景（点外卖/办签证/打游戏排位…）
- **换场景模板**：`SCENES` 数组里每项就是一张场景卡（标题/描述/提示词/注意事项），照抄结构改内容
- **换供应商**：CC Switch 里添加新的供应商即可；DeepSeek 之外的国内厂商若提供 Anthropic 兼容端点，同样适用
- **改安装版本**：替换 `安装包/` 里的 MSI 并更新 `wizard.ps1` 顶部的文件名常量

## 安全与隐私设计

- 密钥只在内存/脚本运行期使用；验证请求由浏览器/PowerShell 直连 `api.deepseek.com`，无任何第三方中转
- 教学网页不写入 localStorage 之外的任何位置，不上传数据；file:// 页面间共享存储域，故密钥刻意不落 localStorage
- 向导与体检助手写配置前一律时间戳备份（`settings.backup-*.json`）
- 红线教育内置：脱敏、防幻觉、"AI 是助理不是决策者"写进课程与人设模板

## 已知限制

- 仅支持 Windows 10/11 x64
- CC Switch 切换供应商时会整体重写 `settings.json`（上游已知行为），自定义字段可能被清——本工具包写入前自动备份可兜底
- 浏览器密钥自检可能被浏览器跨域策略拦截（不影响配置本身，终端/体检助手验证为准）
- 教学页面对 IE 不友好，请使用 Edge/Chrome 等现代浏览器

## FAQ

**Q：为什么选 DeepSeek 而不是 XX？** 按量预付费（无盗刷风险）、官方提供 Anthropic 兼容端点（Claude Code 无缝切换）、价格对学生友好（晚间/周末半价）、国内直连稳定。

**Q：一个月到底花多少钱？** 轻度 10~30 元。打开教学程序的费用计算器拖一下滑块就有你的答案，还能查实时余额。

**Q：和直接用网页版 DeepSeek 有什么区别？** 网页版是聊天（免费），本工具包装的是 Agent（能操作你文件夹里的文件、交付成品）。日常问答用免费 App，干活用 Agent——费用课里专门教了这套分工。

**Q：我对 PowerShell 脚本不放心？** 全部源码在仓库里明文可审（`wizard.ps1`/`check-ai.ps1`），只读写本文件夹与 `~/.claude` 标准配置。
